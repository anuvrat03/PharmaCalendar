# 💊 PharmaVibe

A single-page dashboard that delivers **daily pharma intelligence** for professionals — launches, recalls, warning letters, M&A, awards, and stock movements — all in one elegant view.

![PharmaCalendar Preview](https://img.shields.io/badge/status-live-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ Features

- 📅 **Today's intelligence** — all major pharma news for the current day
- 🏷️ **Categorized updates** — Launches · Recalls · Warning Letters · Awards · M&A · Stock Moves
- 🎨 **Elegant, modern UI** — clean typography (Inter), soft shadows, pill filters
- 📱 **Fully responsive** — works on desktop, tablet, and mobile
- ⚡ **Zero dependencies** — pure HTML, CSS, and Font Awesome icons
- 🚀 **Instant load** — no frameworks, no build step
